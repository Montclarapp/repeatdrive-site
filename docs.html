How to use RepeatDrive

1. Select one activity

Open Pipedrive Activities and select exactly one activity with a due date.

2. Make it recurring

Open More actions, choose Make recurring, then select daily, weekly or monthly recurrence, an interval, and optionally an end date.

3. Let RepeatDrive create the next activity

RepeatDrive creates normal Pipedrive activities automatically. The subject, activity type, owner, CRM links, due time, duration and notes are preserved when supported.

4. Stop whenever you want

Stopping a series prevents future occurrences. Activities already created remain untouched.

Important notes

  • The source activity must have a due date.
  • External calendar attendees are not automatically reinvited in V1.
  • RepeatDrive requests only Pipedrive base access plus Activities full access.
